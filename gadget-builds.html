Build it yourself.

8 gadget builds for Meta's open-source Muse hardware platform. Every build: a real parts list with buy links, and step-by-step instructions. No soldering required — breadboard-friendly.

Before you build anything

  1. Get your free SDK token at gadgets.muse.ai.
  2. Grab the firmware + examples: facebookincubator/muse-gadget-sdk (ESP32 and Linux/Raspberry Pi).
  3. Flash the ESP32 example to your board with ESP-IDF, then pair in the Muse app: Settings > Devices — turn on Developer mode, look for devices starting with MuseGadget.
  4. Wire the parts per the build below, install the matching skill from the repo, and talk to Muse through your hardware.
BUILD 01

Briefing Display

E-paper desk display. Your morning briefing, calendar, and weather — always on, sips power.

~$57Easy~1 hr
  • ESP32 dev board$12.99
  • Waveshare 4.2" e-paper module$31.49
  • Jumper wire kit (560pc)$12.99
  1. Connect the e-paper module to the ESP32 over SPI: MOSI→23, SCK→18, CS→5, DC→17, RST→16, BUSY→4.
  2. Flash the SDK's display example; set your location in the config.
  3. Pair the board in the Muse app (Developer mode → MuseGadget).
  4. Install the briefing skill from the repo's skills/ folder.
  5. Ask Muse "what's my morning briefing" — it renders to the e-paper.

BUILD 02

Voice Button

Big satisfying arcade button. Smack it, talk, Muse answers out loud. The whole agent in one button.

~$65Medium~2 hrs
  • FireBeetle ESP32-S3 board$20.90
  • 60mm arcade button w/ LED$5.95
  • INMP441 I2S microphone$12.90
  • MAX98357A amp (5-pack)$22.99
  • 3" 4Ω 3W speaker$1.95
  1. Wire the button between GPIO 0 and GND (internal pull-up).
  2. Wire INMP441 over I2S: WS→25, SCK→32, SD→33. Wire the amp: DIN→22, BCLK→26, LRCK→27, speaker to amp output.
  3. Flash the SDK's audio example (I2S in + out).
  4. Pair in the Muse app; enable the voice skill.
  5. Press the button, speak, release — Muse replies through the speaker.
